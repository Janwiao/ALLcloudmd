2. 五個評分面向

個人使用

自己上傳、下載、保存、搜尋、跨裝置與日常管理的方便程度。

團隊使用

多人共同使用、權限、共同編輯、版本追蹤與協作流程。

頻繁修改

同一批工作檔每天反覆修改、儲存、同步、跨裝置更新時的穩定與效率。

公開分享

公開連結、Discord、論壇、網站下載，以及 Shared Traffic / Egress 的限制。

大容量收藏

數 TB 冷資料、歷史版本、素材、壓縮檔長期保存時的成本與體驗。

4. 容量與流量不是同一件事

Storage

倉庫有多大。只決定同時可以放多少資料。

Traffic / Egress

資料搬進搬出、或別人下載時產生的傳輸量。

例：10GB 檔案只占 10GB Storage；自己下載 3 次是 30GB；若 1,000 人各下載一次，則約產生 10TB 分享／出站流量。

6. 核心原則

個人 ≠ 團隊

自己好用，不代表多人權限與協作也強。

同步 ≠ 分享

同步很強的服務，不一定適合大量公開下載。

收藏 ≠ 頻繁修改

冷資料倉庫和每天反覆寫入，是完全不同的使用情境。

Storage ≠ Traffic

容量大，不代表公開頻寬大。
