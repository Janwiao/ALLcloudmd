2. 個人使用 vs 分享使用

個人使用

自己上傳、下載、跨裝置、同步、長期保存。重點是 Storage、桌面同步、Online-only、Stream、Virtual Drive、長期價格。

分享使用

把連結給朋友、論壇、Discord 或網站使用者下載。重點是 Shared Link Traffic、Bandwidth、Egress、每日／每月限制，以及熱門檔案會不會被暫停。

例：10GB 檔案只占 10GB Storage；自己抓 3 次是 30GB 傳輸；1,000 人各下載一次則約產生 10TB 分享／出站流量。

4. 逐家分析

Google Drive

個人：★★★★★　分享：★★

Google 生態、文件協作、Stream / Mirror 都很成熟。

適合自己用與少量分享；熱門大型公開檔案可能被暫時限流。

pCloud

個人：★★★★★　分享：★★★

Lifetime、虛擬磁碟、冷資料收藏是最大優勢。

適合當私人總倉庫；公開分享要注意 Shared Link Traffic。

Dropbox

個人：★★★★★　分享：★★★★

同步、多裝置與團隊協作體驗成熟。

Basic 約 20GB/日分享；多數付費方案約 1TB/日；高階商務可到 4TB/日。

MEGA Free

個人：★★★　分享：★★

隱私與大型檔案中轉方便。

Free Transfer quota 會限制持續大量下載，不宜當熱門下載站。

MediaFire Free

個人：★★　分享：★★★★

傳統免費公開分享仍很有優勢。

免費容量小、下載頁有廣告；適合 MOD、補丁、小工具、ZIP。

GitHub Releases

個人：★★　分享：★★★★★

非常適合工具與軟體版本發布。

每個 asset 小於 2GiB；Release 總大小與 bandwidth usage 官方標示無上限。

Cloudflare R2

個人：★★★　分享：★★★★★

Object Storage，Internet egress 免費。

適合 Client、Patch、網站大型檔案；仍需計算 Storage 與 Operations。

5. 怎麼選？

重點是自己用

  • 文件、PDF、照片：Google Drive
  • 多台電腦同步工作：Dropbox
  • 大容量長期收藏：pCloud
  • 臨時中轉：MEGA

重點是給別人下載

  • 工具／程式版本：GitHub Releases
  • 免費分享小檔：MediaFire
  • Client／Patch／網站大型下載：Cloudflare R2
  • 偶爾分享私人檔案：pCloud / Dropbox / Google Drive

6. 核心原則

Storage ≠ Traffic

容量大，不代表分享頻寬也大。

同步雲端 ≠ CDN

Google Drive、Dropbox 很會同步，不代表適合熱門下載站。

收藏 ≠ 發布

冷資料適合 pCloud；大量公開下載更適合 Releases / R2。

重要資料至少兩份

任何單一雲端都不該成為唯一備份。
